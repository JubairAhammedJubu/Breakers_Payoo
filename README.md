# 📖 About the Project

The Payroll Management System is a responsive web application that automates payroll management for organizations.

Instead of calculating salaries manually using spreadsheets or paper records, the system provides an efficient digital platform where HR managers can manage employees, attendance, payroll, bonuses, deductions, and payslips.

Employees can securely log in to view their payroll history and download payslips.
